@Title Migrationsanleitung

@Section Einführung
  PureBasic ist eine moderne Programmiersprache, die sich schnell weiterentwickelt, um technologischen
  Veränderungen zu folgen und dem Programmierer stets einen aktuellen Befehlssatz zur Verfügung zu
  stellen. Dies erfordert mitunter Änderungen oder eine Neugestaltung von Teilen der Sprache.
  Obwohl wir versuchen, solche grundlegenden Änderungen so gering wie möglich zu halten, können sie
  vorkommen. Dieser Migrationsleitfaden hilft Ihnen dabei, Ihren Quellcode von einer Version auf eine
  andere zu aktualisieren.
