@Library Dialog

@Overview
  The dialog library allow to easily create complex user interface (GUI) based on an XML definition.
  It features automatic @LibraryLink "gadget" "gadget" layout, which is very useful when creating interface which needs to work
  on different operating systems or working with different @LibraryLink "font" "font" size. @LineBreak
  @LineBreak
  The XML definition can be file based, or created on the fly in memory using the @LibraryLink "xml" "XML" library.
  @LineBreak
  To find a list of all supported keywords and attributes of this library, see @Link "OpenXMLDialog" "here".
  
@CommandList

@ExampleFile All Dialog.pb

@SupportedOS

;--------------------------------------------------------------------------------------------------------

@Function Result = CreateDialog(#Dialog)

@Description
  Create a new uninitialized dialog. To initialize the dialog, use @@OpenXMLDialog (to open it as its
  own window) or @@XmlDialogGadget (to create it as a gadget embedded in an existing window).

@Parameter "#Dialog"
  A number to identify the new dialog. @ReferenceLink "purebasic_objects" "#PB_Any" can be used
  to auto-generate this number.

@ReturnValue
  Returns nonzero if the dialog was created successfully and zero if not.
  If @#PB_Any was used as the #Dialog parameter, then the auto-generated number is returned in case of success.

@SeeAlso
  @@OpenXMLDialog, @@XmlDialogGadget, @@FreeDialog
  
@SupportedOS

;--------------------------------------------------------------------------------------------------------

@Function Result$ = DialogError(#Dialog)

@Description
  Returns the last error message (in english) to get more information about dialog creation failure after
  @@OpenXMLDialog or @@XmlDialogGadget.

@Parameter "#Dialog"
  The dialog to use.

@ReturnValue
  Returns the error message. If no additional information is available, then the error message can be empty.

@SeeAlso
  @@CreateDialog, @@OpenXMLDialog, @@XmlDialogGadget

@SupportedOS

@Function Result = DialogGadget(#Dialog, Name$)

@Description
  Returns the gadget number of the specified gadget name.

@Parameter "#Dialog"
  The dialog to use.

@Parameter "Name$"
  The name of the gadget, as specified in the XML file (using the 'name' attribute).

@ReturnValue
  Returns the gadget number of the specified gadget name, or -1 if the gadget isn't found in the
  dialog. @LineBreak
  For a dialog created with @@XmlDialogGadget, the root gadget itself can also be retrieved this way,
  by giving the root <window> element a 'name' attribute in the XML.

@SeeAlso
  @@CreateDialog, @@OpenXMLDialog, @@XmlDialogGadget

@SupportedOS

@Function Result = DialogWindow(#Dialog)

@Description
  Returns the window number of the dialog. It allows to use any @LibraryLink "window" "window" related
  commands with the dialog. The dialog has to be initialized successfully with @@OpenXMLDialog before
  using this command.

@Parameter "#Dialog"
  The dialog to use.

@ReturnValue
  Returns the window number of the specified dialog, or -1 if the dialog was created with
  @@XmlDialogGadget instead of @@OpenXMLDialog, as it has no window of its own in that case.

@SeeAlso
  @@CreateDialog, @@OpenXMLDialog, @@XmlDialogGadget

@Function DialogLanguage(Map())

@Description
  Sets the texts used by the 'lang' attribute of the dialog XML elements, and updates all the dialogs
  which are already opened. It allows to easily translate a dialog, or to change its language while the
  program runs. @LineBreak
@LineBreak
  In the XML, an element with a 'lang' attribute (like lang="Main:Ok") displays the text found
  in the map with this key. If the element also has a 'text' attribute, it is appended to the language
  text (useful for a fixed suffix like ":"). If the key isn't found in the map, the key itself is displayed,
  so a missing translation is easy to spot. @LineBreak
@LineBreak
  The 'lang' attribute is supported by the <window> title, the gadgets text, the panel <tab> elements
  and the <item> and <column> elements.

@Parameter "Map()"
  A string map (Map Name$()) with the language texts. The map keys are the values used in the 'lang'
  attributes, they are not case sensitive. The map is copied, so it can be changed or freed after the call.
  An empty map removes all the language texts.

@NoReturnValue

@Remarks
  Only the texts coming from a 'lang' attribute are changed when the language is updated: the content
  modified by the user (like the text of a @@StringGadget) is kept. As the new texts can have a different
  size, the opened dialogs are recalculated like with @@RefreshDialog. The dialogs opened after the call
  use the current language as well.

@Example
@Code
  #Dialog = 0
  #Xml = 0

  XML$ = "<window name='test' lang='Main:Title' flags='#PB_Window_ScreenCentered | #PB_Window_SystemMenu'>" +
         "  <vbox>" +
         "    <text lang='Main:Name' text=':'/>" +
         "    <string/>" +
         "    <combobox name='language'>" +
         "      <item text='English'/>" +
         "      <item text='Français'/>" +
         "    </combobox>" +
         "  </vbox>" +
         "</window>"

  NewMap English$()
  English$("Main:Title") = "Welcome"
  English$("Main:Name")  = "Your name"

  NewMap French$()
  French$("Main:Title") = "Bienvenue"
  French$("Main:Name")  = "Votre nom"

  DialogLanguage(English$())

  If ParseXML(#Xml, XML$) And XMLStatus(#Xml) = #PB_XML_Success
    If CreateDialog(#Dialog) And OpenXMLDialog(#Dialog, #Xml, "test")
      SetGadgetState(DialogGadget(#Dialog, "language"), 0)

      Repeat
        Event = WaitWindowEvent()
        If Event = #PB_Event_Gadget And EventGadget() = DialogGadget(#Dialog, "language")
          If GetGadgetState(EventGadget()) = 1
            DialogLanguage(French$())
          Else
            DialogLanguage(English$())
          EndIf
        EndIf
      Until Event = #PB_Event_CloseWindow
    Else
      Debug "Dialog error: " + DialogError(#Dialog)
    EndIf
  Else
    Debug "XML error: " + XMLError(#Xml) + " (Line: " + XMLErrorLine(#Xml) + ")"
  EndIf
@EndCode

@SeeAlso
  @@OpenXMLDialog, @@RefreshDialog

@SupportedOS

@Function Result = FoldDialogElement(#Dialog, Name$, State)

@Description
  Folds or unfolds the specified dialog element. A folded element and all its children are hidden
  and take no room in the layout. It's the same as the 'folded' XML attribute, but at runtime. @LineBreak
@LineBreak
  The dialog window is resized by the size of the element: it shrinks when the element is folded and
  grows when it is unfolded. Any extra size set by the program or the user is kept. A maximized window
  keeps its size and the other elements use the free space. The dialog is then recalculated like with
  @@RefreshDialog.

@Parameter "#Dialog"
  The dialog to use.

@Parameter "Name$"
  The 'name' attribute of the element to fold or unfold. Any element can be used, including the layout
  elements like <vbox> or <gridbox> (not only the gadgets).

@Parameter "State"
  @#True to fold the element, @#False to unfold it.

@ReturnValue
  Returns nonzero if the element has been found, zero otherwise.

@Remarks
  When an element is unfolded, its children are only shown again if none of its parents is still folded.
  The children which are folded themselves stay folded.

@Example
@Code
  #Dialog = 0
  #Xml = 0

  XML$ = "<window name='test' flags='#PB_Window_ScreenCentered | #PB_Window_SystemMenu'>" +
         "  <vbox expand='no'>" +
         "    <checkbox name='more' text='Show the options'/>" +
         "    <frame name='options' text='Options' folded='yes'>" +
         "      <vbox>" +
         "        <checkbox text='Option 1'/>" +
         "        <checkbox text='Option 2'/>" +
         "      </vbox>" +
         "    </frame>" +
         "    <button text='OK'/>" +
         "  </vbox>" +
         "</window>"

  If ParseXML(#Xml, XML$) And XMLStatus(#Xml) = #PB_XML_Success
    If CreateDialog(#Dialog) And OpenXMLDialog(#Dialog, #Xml, "test")
      Repeat
        Event = WaitWindowEvent()
        If Event = #PB_Event_Gadget And EventGadget() = DialogGadget(#Dialog, "more")
          FoldDialogElement(#Dialog, "options", 1 - GetGadgetState(EventGadget()))
        EndIf
      Until Event = #PB_Event_CloseWindow
    Else
      Debug "Dialog error: " + DialogError(#Dialog)
    EndIf
  Else
    Debug "XML error: " + XMLError(#Xml) + " (Line: " + XMLErrorLine(#Xml) + ")"
  EndIf
@EndCode

@SeeAlso
  @@OpenXMLDialog, @@RefreshDialog

@SupportedOS

@Function FreeDialog(#Dialog)

@Description
  Free the specified dialog and release its associated memory. If the dialog window was still opened, it will be
  automatically closed. For a dialog created with @@XmlDialogGadget, its gadget is freed instead (the window
  hosting it is left untouched).

@Parameter "#Dialog"
  The dialog to free. If @#PB_All is specified, all the remaining dialogs are freed.

@NoReturnValue

@Remarks
  All remaining dialogs are automatically freed when the program ends.
  
@SeeAlso
  @@CreateDialog

@SupportedOS

;--------------------------------------------------------------------------------------------------------

@Function Result = IsDialog(#Dialog)

@Description
  Tests if the given dialog number is a valid dialog. 

@Parameter "#Dialog"
  The dialog to test.

@ReturnValue
  Returns nonzero if #Dialog is a valid dialog and zero if not.

@Remarks
  This function is bulletproof and can be used with any value. 
  This is the correct way to ensure a dialog is ready to use.

@SeeAlso
  @@CreateDialog

@SupportedOS

@Function Result = OpenXMLDialog(#Dialog, #XML, Name$ [, x, y [, Width, Height [, ParentID]]])

@Description
  Open the specified dialog and display it on the screen. 
  To access the dialog gadgets use @@DialogGadget. To get the window number of this dialog use @@DialogWindow. @LineBreak
@LineBreak
  @@UseDialogScintillaGadget, @@UseDialogOpenGLGadget, @@UseDialogWebGadget and @@UseDialogWebViewGadget can be used to
  enable support for these gadgets in the dialog lib. They are not enabled by default to reduce the dialog
  library size footprint.

@Parameter "#Dialog"
  The dialog to use. It has to be previously created with @@CreateDialog.

@Parameter "#XML"
  The @LibraryLink "xml" "xml" to use. It has to be previously created with @@LoadXML, @@CreateXML, @@CatchXML or @@ParseXML.
  That means it's possible to create dialogs on the fly with @@CreateXML, @@CatchXML or @@ParseXML.
  See below for the supported XML attributes. When including XML in the code, it may be easier to use single quote
  in XML for attribute (it's perfectly legal XML syntax).

@Parameter "Name$"
  The name of the dialog to open. An XML file can have several dialogs defined.

@OptionalParameter "x, y"
  The x, y coordinate (in pixels) of the #Dialog. If one of them is @#PB_Ignore, the dialog is centered on the
  screen (or on its parent window if the XML specifies the @#PB_Window_WindowCentered flag).

@OptionalParameter "Width, Height"
  The size (in pixels) of the #Dialog. If the size is smaller than the required size as defined in the XML (after layout
  calculation), then the required size will be used. If omitted, the size of the dialog will be the smallest size required.

@OptionalParameter "ParentID"
  The parent window identifier. A valid window identifier can be retrieved with @@WindowID.

@ReturnValue
  Returns nonzero if the dialog has been successfully opened, returns zero otherwise.
  To get more information about the error which has occurred, use @@DialogError.

@Remarks
  
@FixedFont
----------------------------------------------------------------
   Dialog XML format
----------------------------------------------------------------

  I. Common attributes
  --------------------

  width     - positive integer value or 0 (default="0") (set the "minimum size" of a control)
  height      or "ignore": the object doesn't request any width/height, so it doesn't make its parent grow
              (it gets the size given by the layout)

  id        - #Number identifier for a gadget or a window (default is #PB_Any if not specified). It can be a runtime constant
              or an expression with runtime constants, like "#Gadget_First + 1" (see <compiler> below for the supported operators).
  name      - a string identifying the object (for @@DialogGadget mainly, case insensitive) (default="")
  text      - text string for the object (default="")
  lang      - language key of the text, like "Main:Ok". The text is taken from the map set with @@DialogLanguage, and the
              'text' attribute, if any, is appended to it. If the key isn't in the map, the key itself is displayed.

  folded    - if set to "yes", the object and all its children are hidden and take no room in the layout (default="no").
              Works on any element (layout or gadget). See @@FoldDialogElement to change it at runtime.

  flags     - gadget/window flags in the form "@#PB_Window_Borderless | @#PB_Window_ScreenCentered"  (default="")

  min        - minimum value
  max        - maximum value
  value      - current value

  invisible - if set to "yes", creates the object invisible (default="no")
  disabled  - if "yes", creates the object disabled (gadgets only) (default="no")

  colspan   - inside the <gridbox> element only, allows an element to span multiple rows/columns
  rowspan     (default="1")

  All these attributes are optional.


  II. Root element
  ----------------

  <window> for a single window definition in the same XML file
  </window>
  
  or 
    
  <dialogs> for a multiple window definition in the same XML file
    <window name="FirstWindow">
    </window>
    <window name="SecondWindow">
    </window>
    ...
  </dialogs>

  <dialoggroup> is accepted as an alias of <dialogs>, and the <window> elements can be put in <compiler> blocks
  (see below) to select a different window definition depending of the OS for example.

  The root <window> element is opened as a real window by @@OpenXMLDialog. The very same XML document
  can instead be turned into a gadget (a @@ContainerGadget) with @@XmlDialogGadget - in that case any
  window-only attribute or flag the root <window> may carry (title, screencentered, systemmenu, ...)
  is simply ignored.


  III. Window element
  -------------------

  <window>
  </window>

  Accepted keys in the XML:
  All common attributes and the following:

  minwidth  = 'auto' or a numeric value
  maxwidth  = 'auto' or a numeric value
  minheight = 'auto' or a numeric value
  maxheight = 'auto' or a numeric value

  It allows to set the window bounds. If set to 'auto', then the
  size is calculated depending of the children size requirement.

  forcesize = 'yes' (default) or 'no' - 'yes' is the same as minwidth="auto" and minheight="auto",
              'no' removes the minimum size.
  invisible = 'yes' creates the window invisible (same as the @#PB_Window_Invisible flag)


  - Creates the a window
  - Can have all common attributes.
  - Is a single-element container.
  - If more than one <window> element is present, the 'name' attribute is used to identify them
  - all gui elements can only be placed in here
  
  
  IV. Layout elements
  -------------------
  
  *****************************************************************
  hbox and vbox
  *****************************************************************

    Arrange the elements horizontally or vertically. Can contain
    any number of children.

    Accepted keys in the XML: 
    All common attributes and the following:
  
    spacing   = space to add between the packed childs (default=5)
  
    expand    = yes           - items get bigger to fill all space (default)
                no            - do not expand to fill all space 
                equal         - force equal sized items
                item:<number> - expand only one item if space is available
  

    align     = top/center/bottom      - only applied when expand="no" for the vbox and top is the default
              = left/center/right      - only applied when expand="no" for the hbox et left is the default
                                       - An assembly of vbox and hbox allows a complex alignment top/left/center/bottom/right

  *****************************************************************
  gridbox 
  *****************************************************************
  
    Align elements in a table. Can contain
    any number of children.
    
    Accepted keys in the XML:
    All common attributes and the following:
  
    columns = number of columns (default = 2)
  
    colspacing = space to add between columns/rows (default = 5)
    rowspacing
  
    colexpand = yes           - items get bigger to fill all space
    rowexpand   no            - do not expand to fill all space
                equal         - force equal sized items
                item:<number> - expand only one item if space is available
  
                for colexpand, Default=yes, For rowexpand, Default=no
  
    Any child within a gridbox can have these keys:
  
    colspan = number of columns to span (default = 1)
    rowspan = number of rows to span
  
  *****************************************************************
  multibox
  *****************************************************************
   
    A box with multiple childs in the same position. Used to put multiple containers
    inside and show only one of them at a time. Can contain
    any number of children.
   
    Accepted keys in the XML:

    All common attributes.
    
  *****************************************************************
  singlebox
  *****************************************************************
   
    A box with just one child. Used only to apply extra margin/alignment properties to a child.
    Its called a box (as all virtual containers are called that).

    Accepted keys in the XML:
    
    All common attributes and the following:
  
    margin = margin around the content (default = 10)
             can be a single number (= all margin), or a combination of
             top:<num>,left:<num>,right:<num>,bottom:<num>,vertical:<num>,horizontal:<num>
             example: "vertical:5,left:10,right:0"
  
    expand = yes        - expand child to fill all space (default)
             no         - no expanding
             vertical   - expand vertically only
             horizontal - expand horizontally only
  
    expandwidth  = max size to expand the children to. If the requested size is larger than
    expandheight   this setting then the request size is used (ie the content does not get smaller)
                   default=0
  
    align  = combination of top,left,bottom,right and center. (only effective when expand <> yes)
             example: "top, center" or "top, left" (default) 
             
             
             
  V. Gadget elements
  ------------------

  All common XML attributes are supported. To bind an event procedure directly in the xml, the following attributes
  are available for the gadgets:
  
    onevent      = EventProcedure() - generic event binding, for all event type
    onchange     = EventProcedure() - #PB_EventType_Change binding (only for gadget which support this event type)
    onfocus      = EventProcedure() - #PB_EventType_Focus binding (only for gadget which support this event type)
    onlostfocus  = EventProcedure() - #PB_EventType_LostFocus binding (only for gadget which support this event type)
    onresize     = EventProcedure() - #PB_EventType_Resize binding (only for gadget which support this event type)
    ondragstart  = EventProcedure() - #PB_EventType_DragStart binding (only for gadget which support this event type)
    onrightclick = EventProcedure() - #PB_EventType_RightClick binding (only for gadget which support this event type)
    onleftclick  = EventProcedure() - #PB_EventType_LeftClick binding (only for gadget which support this event type)
    onrightdoubleclick = EventProcedure() - #PB_EventType_RightDoubleClick binding (only for gadget which support this event type)
    onleftdoubleclick  = EventProcedure() - #PB_EventType_LeftDoubleClick binding (only for gadget which support this event type)
    
  The 'EventProcedure()' has to be declared as 'Runtime' in the main code, and has to respect the BindEvent() procedure
  format. Under the hood, BindGadgetEvent() is called with the specified procedure.
  
  Supported gadgets:

  <button>
  <buttonimage>
  <calendar>
  <canvas>
  <checkbox>
  <combobox>
  <container> - single element container
  <date>
  <editor>
  <explorercombo>
  <explorerlist>
  <explorertree> 
  <frame> - single element container (with standard borders only)
  <hyperlink>
  <ipaddress>
  <image>
  <listicon> 
  <listview>
  <option group> - use the same 'group' number to create linked @@OptionGadget.
  <opengl> - UseDialogOpenGLGadget() needs to be called to enable <opengl> support.
  <panel> - can contain <tab> items only
  <progressbar min max value> 
  <scintilla> - callback remains empty. UseDialogScintillaGadget() needs to be called to enable <scintilla> support.
  <scrollarea scrolling="vertical,horizontal or both (default)" innerheight="value or auto (default)" innerwidth="value or auto (default)" step> - single element container, scrolling value determines growth behavior. <scroll> is accepted as an alias.
  <scrollbar min max page value> - page = page length.
  <shortcutgadget> - a @@ShortcutGadget. <shortcut> without 'key' attribute creates a @@ShortcutGadget as well.
  <spin min max value>
  <splitter firstmin="value or auto" secondmin> - must contain 2 subitems, so its a 2 item container basically, minimum size is determined by contained gadgets. If "auto" is specified, the min value will be the minimum size of the child.
  <string>
  <text>
  <trackbar min max value>
  <tree>
  <web> - UseDialogWebGadget() needs to be called to enable <web> support.
  <webview> - UseDialogWebViewGadget() needs to be called to enable <webview> support.

  Gadget related elements:
  <tab> - single element container, for panel tabs (attributes 'text' and 'lang' are supported).

  <item> - adds an item to its parent <combobox>, <listview>, <tree> or <listicon>.
           Supported attributes: 'text', 'lang' and 'sublevel' (for <tree> only).
  <column> - adds a column to its parent <listicon> or <explorerlist>. The default columns of the gadget are
           removed when the first <column> is added. Supported attributes: 'text', 'lang' and 'width'.
           See the "Items and columns" example below.

  Special elements:
  <empty> - an empty element, useful when it's needed to have space between element, to align them to borders for example.

  <shortcut key id> - adds a keyboard shortcut to the dialog window, like @@AddKeyboardShortcut. It doesn't take
           any room in the layout and is only supported with @@OpenXMLDialog.
           key - the #PB_Shortcut constants, which can be combined with '|' (like "#PB_Shortcut_Control | #PB_Shortcut_S").
                 Runtime constants and numbers are accepted as well.
           id  - the menu event number, as a runtime constant or a number. It is received with @@EventMenu.
           See the "Keyboard shortcuts" example below.

  <compiler if="expression"> ... <compilerelse/> ... </compiler>
           Includes its children only if the expression is true, or the children after <compilerelse/> if it is false
           (<compilerelse/> is optional). It can be used anywhere in the dialog, also around <window> elements.
           As the XML is read when the program runs, the expression is evaluated at runtime when the dialog is opened.
           The expression supports:
             - numbers (decimal, or hexadecimal with '$')
             - constants declared with 'Runtime' in the program (like the 'id' attribute)
             - variables declared with 'Runtime' in the program
             - Defined(Name, #PB_Constant) to test if a runtime constant exists
             - #True, #False, #PB_Compiler_OS, #PB_OS_Windows, #PB_OS_Linux and #PB_OS_MacOS
             - the operators ( ), unary -, Not, *, /, +, -, =, <>, <, >, <=, >=, And, Or, Xor

           In XML, the '<' character of an attribute value must be written '&lt;' (like "#Value &lt;= 10").
           A compiler constant like #PB_Compiler_Debugger can be used once declared with 'Runtime' in the program.
           See the "Compiler conditions" example below.

@EndFixedFont  

@Example Simple resizable dialog

@Code
  #Dialog = 0
  #Xml = 0
  
  XML$ = "<window id='#PB_Any' name='test' text='test' minwidth='auto' minheight='auto' flags='#PB_Window_ScreenCentered | #PB_Window_SystemMenu | #PB_Window_SizeGadget'>" +
         "  <panel>" +
         "    <tab text='First tab'>" +
         "      <vbox expand='item:2'>" +
         "        <hbox>" +
         "          <button text='button 1'/>" +
         "          <checkbox text='checkbox 1'/>" +
         "          <button text='button 2'/>" +
         "        </hbox>" +
         "        <editor text='content' height='150'/>" +
         "      </vbox>" +
         "    </tab>" +
         "    <tab text='Second tab'>" +
         "    </tab>" +
         "  </panel>" +
         "</window>"
  
  If ParseXML(#Xml, XML$) And XMLStatus(#Xml) = #PB_XML_Success
    
    If CreateDialog(#Dialog) And OpenXMLDialog(#Dialog, #Xml, "test")
      
      Repeat
        Event = WaitWindowEvent()
      Until Event = #PB_Event_CloseWindow 
      
    Else  
      Debug "Dialog error: " + DialogError(#Dialog)
    EndIf
  Else
    Debug "XML error: " + XMLError(#Xml) + " (Line: " + XMLErrorLine(#Xml) + ")"
  EndIf
@EndCode  

@Example Multibox example

@Code
    #Dialog = 0
  #Xml = 0
  
  Runtime Enumeration Gadget
    #ListView
    #GeneralContainer
    #EditorContainer
    #BackupContainer
  EndEnumeration
  
  Procedure ShowPanels()
    
    HideGadget(#GeneralContainer, #True)
    HideGadget(#EditorContainer, #True) 
    HideGadget(#BackupContainer, #True)
    
    Select GetGadgetState(#ListView)
      Case 0
        HideGadget(#GeneralContainer, #False)
        
      Case 1
        HideGadget(#EditorContainer, #False)
        
      Case 2
        HideGadget(#BackupContainer, #False)
    EndSelect
  EndProcedure
  
  Runtime Procedure OnListViewEvent()
    ShowPanels()
  EndProcedure
  
  XML$ = "<window id='#PB_Any' name='test' text='Preferences' minwidth='auto' minheight='auto' flags='#PB_Window_ScreenCentered | #PB_Window_SystemMenu | #PB_Window_SizeGadget'>" +
         "  <hbox expand='item:2'>" +
         "    <listview id='#ListView' width='100' onEvent='OnListViewEvent()'/>" +
         "    <multibox>" +
         "" +
         "      <container id='#GeneralContainer' invisible='yes'>" +
         "        <frame text='General'>" +
         "          <vbox expand='no'>" +
         "            <checkbox text='Enable red light'/>" +
         "            <checkbox text='Enable green light'/>" +
         "          </vbox>" +
         "        </frame>" +
         "      </container>" +
         "" +
         "      <container id='#EditorContainer' invisible='yes'>" +
         "        <frame text='Editor'>" +
         "          <vbox expand='no'>" +
         "            <checkbox text='Set read only mode'/>" +
         "            <checkbox text='Duplicate line automatically'/>" +
         "            <checkbox text='Enable monospace font'/>" +
         "          </vbox>" +
         "        </frame>" +
         "      </container>" +
         "" +
         "      <container  id='#BackupContainer' invisible='yes'>" +
         "      <frame text='Backup'>" +
         "        <vbox expand='no'>" +
         "          <checkbox text='Activate backup'/>" +
         "        </vbox>" +
         "      </frame>" +
         "      </container>" +
         "" +
         "    </multibox>" +
         "  </hbox>" +
         "</window>"
  
  If ParseXML(#Xml, XML$) And XMLStatus(#Xml) = #PB_XML_Success
    
    If CreateDialog(#Dialog) And OpenXMLDialog(#Dialog, #Xml, "test")

@Function Result = XmlDialogGadget(#Dialog, #XML, Name$ [, x, y [, Width, Height]])

@Description
  Creates the specified dialog as a gadget (a @@ContainerGadget), instead of opening it as its own
  window like @@OpenXMLDialog does. This allows a dialog defined in XML to be embedded inside an
  existing window, next to other gadgets. @LineBreak
@LineBreak
  It uses exactly the same XML format as @@OpenXMLDialog (see its documentation for the full XML
  reference) - the very same XML document can be used with either command: the root <window> element
  becomes the created @@ContainerGadget, and any window-only attribute or flag it may still carry
  (title, screencentered, systemmenu, ...) is simply ignored. @LineBreak
@LineBreak
  The gadget is created inside the currently active window, exactly like @@ContainerGadget itself, so
  @@XmlDialogGadget has to be called after opening (or after selecting, with @@UseGadgetList) the
  window that should host it. @LineBreak
@LineBreak
  To access the dialog gadgets, including the root gadget itself, use @@DialogGadget (give the root
  <window> element a 'name' attribute in the XML to retrieve it). Unlike a dialog opened with
  @@OpenXMLDialog, @@DialogWindow returns -1 for a dialog created with @@XmlDialogGadget, as it has
  no window of its own. @LineBreak
@LineBreak
  @@UseDialogScintillaGadget, @@UseDialogOpenGLGadget, @@UseDialogWebGadget and @@UseDialogWebViewGadget can be used to
  enable support for these gadgets in the dialog lib. They are not enabled by default to reduce the dialog
  library size footprint.

@Parameter "#Dialog"
  The dialog to use. It has to be previously created with @@CreateDialog.

@Parameter "#XML"
  The @LibraryLink "xml" "xml" to use. It has to be previously created with @@LoadXML, @@CreateXML, @@CatchXML or @@ParseXML.
  See @@OpenXMLDialog for the supported XML attributes.

@Parameter "Name$"
  The name of the dialog to use. An XML file can have several dialogs defined.

@OptionalParameter "x, y"
  The x, y coordinate (in pixels) of the #Dialog gadget, relative to its container.

@OptionalParameter "Width, Height"
  The size (in pixels) of the #Dialog gadget. If the size is smaller than the required size as defined
  in the XML (after layout calculation), then the required size will be used. If omitted, the size of
  the dialog will be the smallest size required.

@ReturnValue
  Returns nonzero if the dialog gadget has been successfully created, returns zero otherwise.
  To get more information about the error which has occurred, use @@DialogError.

@Remarks
  Resizing the created gadget (for example with @@ResizeGadget, or from the host window's own resize
  handling) automatically relayouts its children to fit the new size, the same way a dialog window
  opened with @@OpenXMLDialog does.

@Example

@Code
  #Dialog = 0
  #Xml = 0
  #Window = 0

  XML$ = "<window name='test'>" +
         "  <vbox expand='item:3'>" +
         "    <string name='name' text='Your name' />" +
         "    <checkbox name='newsletter' text='Subscribe to the newsletter' />" +
         "    <editor name='comment' height='80' />" +
         "  </vbox>" +
         "</window>"

  If OpenWindow(#Window, 0, 0, 320, 240, "XmlDialogGadget", #PB_Window_ScreenCentered | #PB_Window_SystemMenu | #PB_Window_SizeGadget)

    TextGadget(#PB_Any, 10, 10, 300, 20, "This window hosts a dialog defined in XML:")

    If ParseXML(#Xml, XML$) And XMLStatus(#Xml) = #PB_XML_Success

      If CreateDialog(#Dialog) And XmlDialogGadget(#Dialog, #Xml, "test", 10, 35, 300, 160)

        ; The dialog container gadget itself is retrieved with the name of its root <window> element
        Container = DialogGadget(#Dialog, "test")

        Ok = ButtonGadget(#PB_Any, 210, 205, 100, 25, "OK")

        Repeat
          Event = WaitWindowEvent()

          Select Event
            Case #PB_Event_SizeWindow
              ; Resizing the container automatically relayouts the dialog gadgets inside it
              ResizeGadget(Container, #PB_Ignore, #PB_Ignore, WindowWidth(#Window) - 20, WindowHeight(#Window) - 80)
              ResizeGadget(Ok, WindowWidth(#Window) - 110, WindowHeight(#Window) - 35, #PB_Ignore, #PB_Ignore)

            Case #PB_Event_Gadget
              If EventGadget() = Ok
                Debug "Name: " + GetGadgetText(DialogGadget(#Dialog, "name"))
                Debug "Newsletter: " + GetGadgetState(DialogGadget(#Dialog, "newsletter"))
              EndIf
          EndSelect
        Until Event = #PB_Event_CloseWindow

      Else
        Debug "Dialog error: " + DialogError(#Dialog)
      EndIf
    Else
      Debug "XML error: " + XMLError(#Xml) + " (Line: " + XMLErrorLine(#Xml) + ")"
    EndIf
  EndIf
@EndCode

@SeeAlso
  @@OpenXMLDialog, @@DialogGadget, @@DialogWindow
