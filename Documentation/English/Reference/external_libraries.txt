@Title External Libraries

@Section Overview

  PureBasic (and SpiderBasic) make use of a number of third-party open source
  libraries, which are compiled directly into the various PureBasic libraries
  at build time. The table below lists each of these external libraries,
  together with the exact version currently used and its official release date.
  @LineBreak
  @LineBreak
  See also the @ReferenceLink "license_application" "License file for PureBasic applications"
  for the copyright and license text of each of these components.
