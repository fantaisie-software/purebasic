@Library Help

@Overview

  The help feature is a very important component for any type of software. It allows the end-users
  the opportunity to discover the software's features quickly and easily. The PureBasic help
  functions allow the programmer the ability to display standard help files with both global and
  contextual support.
@LineBreak
@LineBreak
  On Microsoft Windows, there are two different help-file formats which are supported:
  The ".hlp" format (which is the old) and the ".chm" format (which is the new). The ".chm"
  format is based on HTML, which stands for Hyper Text Markup Language.
@LineBreak
@LineBreak
    On Linux, the 'yelp' tool is used, see @InternetLink "https://en.wikipedia.org/wiki/Yelp_(software)" "Yelp on Wikipedia".
@LineBreak
@LineBreak
    On macOS, the native help viewer tool is used, see @InternetLink "https://developer.apple.com/library/archive/documentation/Carbon/Conceptual/ProvidingUserAssitAppleHelp/authoring_help/authoring_help_book.html#//apple_ref/doc/uid/TP30000903-CH206-CIHEAADH" "Help Viewer".

@Function CloseHelp()

@Description
  Close the help window previously opened with @@OpenHelp.

@NoParameters
@NoReturnValue

@SeeAlso
  @@OpenHelp

@SupportedOS All

;--------------------------------------------------------------------------------------------------------

@Function OpenHelp(Filename$, Topic$)

@Description
  Open and display a help window. 

@Parameter "Filename$"
  On Windows, the name of either the .chm or .hlp file to be opened. @LineBreak
  On Linux, the name of an help file which can be opened with the 'yelp' tool, see @InternetLink "https://en.wikipedia.org/wiki/Yelp_(software)" "Yelp on Wikipedia". @LineBreak
  On MacOS, the name of an help file which can be opened with the native macOS help viewer tool, see @InternetLink "https://developer.apple.com/library/archive/documentation/Carbon/Conceptual/ProvidingUserAssitAppleHelp/authoring_help/authoring_help_book.html#//apple_ref/doc/uid/TP30000903-CH206-CIHEAADH" "Help Viewer".

@Parameter "Topic$"
  The internal name of the page to display, if the Topic$ parameter is not an empty string, 
  the OpenHelp function will display the specified page. 

@NoReturnValue

@Remarks
  Note: this command is not supported by the QT subsystem.

@Example
@Code
  OpenHelp("help.chm", "index.htm")
  OpenHelp("help.chm", "print.txt")
@EndCode

@SeeAlso
  @@CloseHelp

@SupportedOS All
